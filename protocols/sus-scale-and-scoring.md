# System Usability Scale for the deployment method

Source: Brooke, J. (1996), *SUS: A “quick and dirty” usability scale*.

Administer immediately after the deployment attempt. Response options: 1 = strongly disagree, 2 = disagree, 3 = neutral, 4 = agree, 5 = strongly agree.

1. I think that I would like to use this deployment method frequently.
2. I found the deployment method unnecessarily complex.
3. I thought the deployment method was easy to use.
4. I think that I would need support from an experienced person to use this deployment method.
5. I found the functions in this deployment method well integrated.
6. I thought there was too much inconsistency in the deployment method.
7. I imagine that most people would learn to use this deployment method very quickly.
8. I found the deployment method very cumbersome to use.
9. I felt confident using the deployment method.
10. I needed to learn many things before I could use the deployment method.

## Scoring

- Odd-numbered items: contribution = response - 1.
- Even-numbered items: contribution = 5 - response.
- SUS total = sum of item contributions x 2.5, ranging from 0 to 100.

SUS is a relative usability measure rather than a percentage score. The project reports distributions and sample context; it uses 68 only as a common descriptive reference.
