# 数据采集与程序设计 · 使用说明

本文件夹为《多智能体在个人任务流中的应用》研究报告（01-研究报告）的数据采集与程序设计配套，覆盖报告中三个子研究所需的全部工具：知情同意、问卷、访谈、部署可用性测试、日志编码、对比实验、数据分析程序与数据填充对照表。

## 执行顺序

| 阶段 | 内容 | 对应文件夹 | 对应研究报告 |
|---|---|---|---|
| 0 准备 | 阅读本说明与知情同意书，招募参与者 | 01-伦理与合规 | 3.5 伦理与合规 |
| 1 研究1 | 部署可用性测试（3—5名非工作坊成员） | 04-部署可用性测试 | 3.2、4.1 |
| 2 研究2 | 问卷发放与回收（问卷星或本地HTML） | 02-问卷 | 3.3、4.2 |
| 2 研究2 | 半结构化访谈（3—5人） | 03-访谈 | 3.3、4.2 |
| 2 研究2 | 日志导出与编码 | 05-日志编码 | 3.3、4.2 |
| 3 研究3 | 单vs多智能体对比实验 | 06-对比实验 | 3.4、4.3 |
| 4 分析 | 运行数据分析程序，结果填入报告 | 07-数据分析程序、08-数据汇总 | 第四章全部表格 |

## 各子文件夹说明

- **01-伦理与合规**：知情同意书模板，问卷、访谈、日志导出前使用。
- **02-问卷**：问卷星录入版（可直接复制进问卷星）、数据模板CSV（导出后按此格式整理）、本地HTML版（无需问卷星账号，离线收集，一键导出CSV）。
- **03-访谈**：访谈提纲执行版（含开场与追问）与主题编码表。
- **04-部署可用性测试**：执行手册、SUS量表与计分说明、观察记录表。
- **05-日志编码**：编码手册、编码表CSV（主编码＋次编码双列）、记忆指标表CSV。
- **06-对比实验**：执行手册（含交叉抵消设计）、任务材料、盲评打分表、实验数据记录表CSV。
- **07-数据分析程序**：Python脚本，依次运行01→05，自动计算信度、委托边界、假设检验、对比实验与图表。
- **08-数据汇总**：研究报告-数据填充对照表（报告每个【 】对应哪份数据），以及程序输出结果存放位置。

## 铁律

1. 所有数据必须真实采集，严禁编造。
2. 报告中的【 】单元格一律由本文件夹的数据产物填入，对照关系见 `08-数据汇总/研究报告-数据填充对照表.md`。
3. 参与者匿名化处理；问卷建议加装"链接码"（参与者自拟随机数字），用于与日志、记忆指标匿名关联，不采集可识别身份的信息。
4. 数据收集全程遵守《南京大学本科生院关于本科生规范使用生成式人工智能工具的指导意见（试行）》与知情同意书约定。
5. 程序运行环境：Python 3.9+，依赖见 `07-数据分析程序/requirements.txt`。安装：`pip install -r requirements.txt`。

## 建议的采集周期

| 数据 | 建议周期 |
|---|---|
| 部署可用性测试 | 1周 |
| 问卷 | 2—3天回收 |
| 访谈 | 1周（与日志并行） |
| 日志导出与编码 | 1周 |
| 对比实验 | 1周（优先级最高） |
