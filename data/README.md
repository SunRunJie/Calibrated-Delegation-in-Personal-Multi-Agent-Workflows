# Collected Data

Participant-level data are restricted under the original consent terms and are not distributed through GitHub.

## Local restricted inputs

Authorized local users may place the following files in `restricted/`:

| Filename | Content |
| --- | --- |
| `survey-responses.csv` | Row-level post-workshop survey responses |
| `deployment-usability.csv` | Five deployment-usability attempts |
| `usage-event-coding.csv` | Coded delegation events |
| `memory-indicators.csv` | Pseudonymously linked memory indicators |
| `comparative-experiment.csv` | Participant-level experimental runs |

The directory is ignored by Git except for its README. Raw values are preserved in their collected form; the plotting script maps research-facing labels into English without changing observations.

## Public aggregate results

Non-disclosive statistics used to verify reported results are published in `../results/tables/`. They contain no participant IDs, link codes, event-level dates, or individual trajectories.
